# Credit Scoring — Кредитный скоринг

## Описание

Проект предсказывает вероятность дефолта по кредиту на основе данных заявителя. Пользователь заполняет форму, модель выдаёт решение — одобрить кредит или отказать.

## Запуск

### 1. Установить зависимости

```bash
pip install -r requirements.txt
```

### 2. Запустить FastAPI (в первом терминале)

```bash
uvicorn service:app --reload
```

API будет доступно по адресу: `http://127.0.0.1:8000`

### 3. Запустить Streamlit (во втором терминале)

```bash
streamlit run app.py
```

Интерфейс откроется по адресу: `http://localhost:8501`

## Результаты модели

| Метрика | Значение |
|---|---|
| PR-AUC | 0.237 |
| Precision | 0.14 |
| Recall | 0.63 |

### Что это значит для бизнеса

**Recall 0.63** — модель выявляет 63% реальных неплательщиков. Из каждых 100 клиентов, которые не вернут кредит, банк заранее отсеивает 63 из них. Это снижает кредитные потери.

**Precision 0.14** — из всех клиентов которым модель отказывает, только 14% действительно являются неплательщиками. Остальные 86% — хорошие клиенты, которые получили отказ ошибочно. Это упущенная прибыль банка.
